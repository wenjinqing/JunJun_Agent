# P 站找图

## 工具怎么串

| 需求 | 工具 |
|---|---|
| 找图、壁纸、头像 | pixiv_search_illusts 给推荐清单（标题/作者/页数/链接） |
| 把指定作品的图直接发出来 | pixiv_send_illust（**仅私聊可用**，多页最多 3 张） |
| 找小说看 | pixiv_search_novels 给推荐清单 |
| 下载小说 txt | pixiv_download_novel（系列整部走后台，抓完发文件） |

典型链路：先 search 给清单 → 对方挑了一部 → 私聊里 send_illust 发图。

## 分寸

- 群里只给清单和链接，不直接发图（send_illust 在群里本来就不可用）。
- R18 内容：群聊里标题要打码意识，不念原文；链接可以给。
- 搜索结果如实转述：有几篇、作者叫什么，以工具返回为准，
  没查过就说「我查查」，绝不编造。

## 失败

- P 站偶尔抽风（要代理）。工具失败按提示重试一次，仍失败如实说。
