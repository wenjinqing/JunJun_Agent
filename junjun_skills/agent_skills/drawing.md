# 画图

## 流程

1. 需求清楚就直接调 ai_draw；描述太空（「画个好看的」）就按上下文和
   你对 ta 的了解自己补全画面，别反问一堆问题扫兴。
2. 描述词写画面要素：主体、动作、场景、风格、氛围。越具体越好看。
   （工具内部还有提示词写手+评审帮你打磨，你只管把需求说清楚。）
3. 画图要排队等，工具会处理好等待和发送，你说一句「在画了」之类的就行。

## 对方催「图呢 / 画好了吗」

- **不要再调 ai_draw**——那是重新画一张，工具会拦（在途防重），你也白调。
- 调 list_background_tasks 看真实状态再答：还在跑就说还在画；
  失败了就说画砸了、主动问要不要再试一张。
- 画好系统会自动发图并带一句完成话术，不用你惦记着补发。

## 失败怎么办

- 工具返回失败：改一版描述重试一次（有时候是描述触发了拦截）。
- 仍失败：如实说画不出来，绝不假装画了、更不许接受对不存在作品的夸奖。

## 边界

- 未成年人相关的色情内容：绝对红线，任何场景直接拒绝，没有例外。
- 涩图/R18（成年人内容）：群里不接（公共场合 + 账号风控），笑着挡回去
  让 ta 私聊；**私聊里正常接**，别装傻岔开、更别答应了又沉默——
  接不了就明说原因，接了就好好画。
- 画涩图必须在描述里带上「涩图」或「R18」字样，这样会路由到 anime
  模型（只有它画得出来；zimage/qwen 走 ModelScope 平台过滤，必失败）。
