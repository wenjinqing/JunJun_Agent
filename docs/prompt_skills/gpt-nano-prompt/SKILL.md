# GPT Image 2 提示词指导规范

本文档根据大量 GPT Image 2 提示词蒸馏整理，目标是形成一套可复用、可扩展、可产品化的提示词写作规范。

核心结论：GPT Image 2 的高质量提示词不是简单堆关键词，而是给模型一份清晰的视觉生产 brief。优秀提示词通常包含：明确任务、明确主体、明确构图、明确风格、明确细节、明确文字、明确保留项、明确禁止项和明确验收标准。

## 总体原则

- 把提示词写成给设计师、摄影师、美术指导的生产说明，而不是关键词列表。
- 先定义最终图像类型，再描述主体、场景、构图、材质、光线、文字和限制。
- 对复杂任务优先使用结构化写法，例如 JSON、分段标题或清单。
- 对可复用场景使用变量占位，例如 `{argument name="角色" default="虞姬"}`。
- 不要只写"高级感""电影感"，要说明高级感来自哪里，例如留白、材质、镜头、光影、版式和叙事层级。
- 对图像编辑类任务，明确哪些必须保留，哪些允许优化，哪些绝对禁止改变。
- 对商业设计类任务，加入数量、位置、尺寸、品牌元素、文字准确性和可生产性约束。

## 通用提示词结构

```text
任务类型：
生成一张什么图，用于什么场景，横版/竖版/比例/完成度。

主体对象：
人物、产品、建筑、场景、道具、品牌元素、文字内容。

视觉设定：
风格、时代、世界观、情绪、色彩、材质、光线、镜头、构图。

布局要求：
画面分区、主体位置、前中后景、留白、文字区域、元素数量。

细节要求：
服装、表情、动作、五官、材质纹理、道具、环境细节、特殊效果。

文字要求：
需要出现的标题、标签、署名、Logo、日期、语言风格、字体气质。

约束要求：
必须保留什么，不能改变什么，不能出现什么。

质量标准：
真实感、完成度、可读性、商业设计感、避免模板感、避免 AI 味。
```

## 通用母版

```text
请生成一张{画面类型}，主题是「{主题}」，画面比例为{比例}，用于{使用场景}。

画面核心：
主体是{主体}，位于{主体位置}，正在{动作/状态}。整体氛围为{情绪}，需要呈现{核心卖点/叙事重点}。

视觉风格：
采用{风格类型}，结合{参考美学}。色彩以{主色}、{辅助色}为主，光线为{光线类型}，材质表现强调{材质关键词}。

构图与镜头：
使用{镜头/视角}，构图为{构图方式}。前景包含{前景元素}，中景包含{中景元素}，背景包含{背景元素}。画面需要有清晰的空间层次和视觉焦点。

细节要求：
保留{必须保留项}，强化{需要强化项}。加入{道具/符号/装饰元素}，但不要让画面杂乱。

文字与版式：
画面中需要出现文字「{文字内容}」，位置在{文字位置}，字体气质为{字体风格}。文字必须清晰、自然融入画面，不要像后期硬贴。

避免：
不要出现{错误内容1}、{错误内容2}、{错误内容3}。避免廉价模板感、过度滤镜、元素堆砌、错误文字、肢体异常、主体变形、无关装饰。
```

## 结构化 JSON 写法

适合复杂设计、产品图、角色设定、品牌周边、UI 报告页。

```json

  "type": "生成图像类型",
  "theme": {
    "subject": "核心主题",
    "mood": "情绪",
    "color_palette": "主色与辅助色"
  },
  "composition": {
    "ratio": "4:3 / 16:9 / 9:16 / 1:1",
    "camera": "镜头与视角",
    "layout": "主体、文字、背景的布局"
  },
  "subject": {
    "identity": "主体身份",
    "appearance": "外观特征",
    "action": "动作状态",
    "expression": "表情气质"
  },
  "environment": {
    "scene": "场景",
    "lighting": "光线",
    "materials": "材质与纹理"
  },
  "text": {
    "title": "需要出现的标题",
    "labels": ["辅助文字1", "辅助文字2"],
    "typography": "字体气质"
  },
  "constraints": {
    "must_keep": ["必须保留项"],
    "avoid": ["禁止项", "常见错误", "不要模板感"]
  }
}
```

## 人像编辑

人像编辑的核心不是"变美"，而是"保留身份 + 局部升级"。

```text
请基于用户上传的正面形象照片，生成一张高完成度的人像美学升级图。

必须严格保留：
本人身份特征、脸部辨识度、五官核心轮廓、年龄感、皮肤真实纹理、原本气质。

允许优化：
面部精神状态、皮肤质感、光线、轮廓清晰度、五官协调度、照片完成度。

禁止：
不要换头，不要变成模板网红脸，不要改变年龄，不要改变种族特征，不要过度磨皮，不要改变服装来制造变化，不要让人认不出原本人。
```

写作要点：
- 明确"同一个人"优先于"更漂亮"
- 把优化范围限制在光线、皮肤质感、精神状态、轮廓清晰度
- 禁止通过换衣服、换发型、换脸型制造变化
- 使用"真实纹理""年龄感""身份特征"等词防止过度美颜

## 动漫角色

动漫类提示词不要只写"二次元美少女"，要明确角色设计、服装结构、配色、表情、动作、背景和特效。

```text
生成一张高完成度动漫角色设计图，角色为「{角色名}」。

角色设定：
年龄感为{年龄}，气质为{气质}，发色为{发色}，发型为{发型}，眼睛为{眼睛描述}，服装为{服装风格}。

设计要求：
画面包含正面主立绘、局部细节、服装结构、配饰、代表性道具和主题色。背景保持干净，辅助图形不能抢主体。

渲染要求：
线条精致，颜色统一，布料、金属、蕾丝、发丝等细节清晰，有高级游戏角色设定表质感。

避免：
不要低质量同人感，不要比例崩坏，不要手指错误，不要背景过花，不要配色混乱。
```

写作要点：
- 角色设计必须包含身份、年龄感、性格、主题色和代表性元素
- 服装不要只写风格名，要写结构、材质、配饰、层次和颜色
- 战斗、魔法、偶像、洛丽塔、国风等类型都要给出清晰的动作和特效逻辑
- 如果是角色设定表，应要求白底、分区、局部细节、服装说明和清晰排版

## 产品包装

产品包装提示词重点是"真实可生产"。需要写清物品阵容、包装结构、材质、数量、品牌露出和尺寸关系。

```text
生成一张品牌周边产品展示图，主题为「{品牌/角色/活动}」。

画面包含：
1 个主包装盒、{数量} 个独立小包装、{数量} 个徽章、{数量} 个钥匙扣、{数量} 件服饰/杯子/贴纸。

要求：
所有物品看起来像真实可生产的实体商品，包装材料精美，印刷清晰，品牌元素统一。产品之间保持合理尺寸比例，摆放自然，有商业摄影完成度。

避免：
不要虚假的 App 组件风，不要厚卡片堆叠感，不要塑料廉价感，不要错误 Logo，不要数量不一致，不要材质混乱。
```

写作要点：
- 写清楚每个物品的数量，避免模型随意增减
- 要求"实体商品""可生产""包装材料""印刷清晰"
- 明确主包装、散装物、赠品、贴纸、徽章等之间的层级
- 对品牌周边要统一 Logo、角色、色彩和图案语言

## 海报封面

海报和封面的共性是：主题强绑定、留白、叙事、电影级光影，避免模板化。

```text
生成一张收藏版电影海报，主题为「{主题}」。

画面设计：
使用{核心人物/物体}作为主视觉轮廓，内部融合该主题最具识别度的场景、人物关系、建筑、符号和道具。整体不是普通拼贴，而是高级叙事合成。

美术风格：
电影海报风格 + {东方/科幻/复古/现实主义}美学。强调真实物理光影、空间纵深、体积光、轻雾、材质质感和克制的冷暖对比。

版式：
大面积留白，标题区域清晰，视觉层级明确，安静、宏大、克制，有宿命感。

避免：
不要杂乱拼贴，不要廉价奇幻素材，不要模板网站风，不要过度装饰，不要无关元素。
```

写作要点：
- 先定义海报类型：电影海报、专辑封面、毕业季海报、活动主视觉、收藏版海报
- 用"主视觉轮廓 + 内部叙事场景"可以提升画面结构感
- 对文字只保留核心标题、副标题、署名、日期，避免大量小字
- 明确"不要商业模板感""不要网站模板风""不要旅游宣传海报感"

## 品牌周边

品牌周边需要把角色、Logo、主题色、包装、社媒样机和实体商品统一起来。

```text
生成一张品牌形象与周边设计项目展示图，主题为「{品牌名/角色名}」。

画面包含：
顶部页眉横幅、主 Logo、副 Logo、角色肖像、产品包装、宣传海报、社交媒体样机、周边商品系列。

周边商品：
T 恤、马克杯、徽章、亚克力钥匙扣、贴纸、糖果包装或其他实体商品。所有商品需要统一主题色、图案语言和品牌识别系统。

要求：
整体像完整的品牌设计提案，不是零散素材拼贴。所有物品具有一致的视觉系统、清晰的层级和真实可生产的质感。
```

写作要点：
- 指定主 Logo、副 Logo、角色肖像和社媒账号
- 把周边分成包装类、服饰类、徽章类、社媒类、宣传类
- 要求"完整品牌设计提案"，防止变成无序拼贴
- 对每个版块给出位置，例如顶部、中左、中右、左下、右下

## UI 报告页

UI 报告页常用于美学分析、Before & After、评估报告、信息卡片。重点是专业感和信息层级。

```text
请生成一张横向 4:3 的高完成度「AI 五官美学升级报告 / Before & After Facial Aesthetic Upgrade Report」。

布局：
左侧为 Before，右侧为 After，中间或下方为分析模块。整体像专业视觉报告，而不是普通修图对比。

要求：
保留本人身份特征，展示局部优化逻辑。信息层级清晰，标题、指标、说明文字、分区边框和对比箭头自然融入画面。

避免：
不要厚卡片，不要 App 组件风，不要模板化仪表盘，不要让报告元素抢走人物主体。
```

写作要点：
- UI 元素要服务主体，不要变成普通 App 截图
- 报告页需要标题、对比区、分析区、结论区，但不能过度堆信息
- 对人物对比图，必须强调身份一致和真实纹理
- 适合用"专业视觉报告""高完成度版式""清晰信息层级"等表达

## 摄影写真

摄影写真提示词要像摄影 brief，明确设备、镜头、视角、灯光、皮肤、服装和环境。

```text
生成一张{设备/镜头}风格的人像摄影图，主体是{人物描述}，场景为{场景}。

相机参数：
设备类型为{iPhone 15 Pro / 全画幅相机 / 胶片相机}，镜头为{焦段}，构图为{视角}，后期处理为{摄影风格}。

主体描述：
人物具有{五官/皮肤/发型/服装/表情/动作}，需要呈现{气质}。

环境与灯光：
场景为{环境}，光线为{色温/方向/强度}，材质和皮肤质感为{质感描述}。

避免：
不要过度磨皮，不要假棚拍感，不要错误服装，不要不自然姿势，不要过度胶片颗粒。
```

写作要点：
- 写设备和焦段能提升摄影感，例如 iPhone 自拍、24mm、低角度、长焦压缩
- 写光线要具体，例如沿海日光、5500K、逆光、柔光箱、霓虹反射
- 写皮肤时用"真实纹理""微反光""自然瑕疵"，防止塑料感
- 对写真风格，明确是街拍、棚拍、胶片、时尚大片、生活感自拍

## 国风叙事

国风叙事类重点是主题识别、东方美学、人物关系、建筑符号、材质和克制光影。

```text
根据「{主题/作品/人物}」生成一张收藏版史诗叙事海报。

画面设计：
使用{核心人物}的巨大侧脸剪影或主体轮廓作为外框，内部生长出最契合主题的完整世界观、标志性场景、角色关系、象征符号、关键建筑、道具与氛围。

风格：
电影海报风格 + 东方现实主义美学。强调真实物理光影、丝绸、石材、木质、肌肤等真实材质，保留柔和空气透视和电影级景深。

避免：
不要廉价古风素材，不要仙侠模板感，不要乱堆宫殿和云雾，不要脱离原主题，不要普通拼贴。
```

写作要点：
- 国风不是元素堆砌，必须让所有元素强绑定主题
- 可使用剪影填充、双重曝光、叙事合成等结构增强高级感
- 材质要具体：丝绸、木、石、纸、墨、瓷、肌肤、烛光
- 光影要克制，避免廉价玄幻发光效果

## 游戏资产

游戏资产类提示词适合角色立绘、技能特效、卡牌主视觉、道具图标、皮肤宣传图。

```text
生成一张{游戏类型}风格的角色主视觉，角色为「{角色名}」，核心技能效果为「{技能效果}」。

角色：
角色拥有{外观特征}，穿着{服装/护甲/皮肤主题}，动作是{战斗动作}。

技能特效：
技能表现为{能量形态/颜色/轨迹/粒子/符号}，需要与角色主题强绑定。

画面：
采用动态构图、低角度或强透视，主体清晰，背景服务技能释放场景。整体有高级抽卡游戏主视觉质感。

避免：
不要技能效果与角色无关，不要武器形状错误，不要特效遮挡主体，不要低质量手游广告感。
```

写作要点：
- 技能必须包含颜色、形态、轨迹、爆发点和主题符号
- 角色动作要明确，例如突刺、跃起、挥剑、召唤、蓄力
- 对卡牌图要强调主视觉、稀有度感、粒子、边缘光和主体识别度
- 如果涉及已有角色，要约束服装颜色、武器形状和标志性元素

## 社媒封面

社媒封面重点是强记忆点、清晰标题、情绪氛围和平台适配。

```text
生成一张{平台/用途}封面图，主题为「{主题}」，比例为{比例}。

画面：
主体位于{位置}，背景为{背景}，整体情绪为{情绪}。标题区域保留清晰留白，视觉焦点明确。

文字：
主标题为「{标题}」，副标题为「{副标题}」，字体气质为{字体风格}。文字需要清晰可读，与画面自然融合。

风格：
整体风格为{青春歌单封面/毕业季海报/低清胶片照片/旧相册记忆/校园回忆/商业封面}。

避免：
不要四角堆满文字、二维码、明显商业 Logo、模板网站风、过度精致广告感、旅游宣传海报感。
```

写作要点：
- 社媒封面要先确定平台比例和视觉焦点
- 文字不宜多，优先保证主标题准确
- 情绪类封面要写空气感、回忆感、季节感、年代感
- 避免过度商业模板化，尤其是毕业季、歌单、校园、旅行等主题

## 文字生成规范

GPT Image 2 可以处理文字，但需要降低复杂度。

- 文字越短越好，核心标题优先。
- 明确文字内容、位置、字体气质和用途。
- 不要同时要求大量小字、二维码、复杂表格和多语言密集排版。
- 需要文字准确时，写"文字必须清晰可读，不要错字、乱码、伪文字"。
- 海报类适合 1 个主标题、1 个副标题、1 个署名或日期。

```text
画面顶部居中出现标题「2026 毕业季」，字体为手写感中文标题字，清晰可读。底部右侧出现署名「青春纪念册」。不要出现二维码、商业 Logo、乱码或无意义小字。
```

## 负面约束规范

不要只写一串负面词，要按错误类型分类。

```text
避免：
身份错误：不要换脸、不要改变年龄、不要改变核心五官。
结构错误：不要多手、多指、肢体扭曲、物体比例错误。
文字错误：不要错字、乱码、伪文字、无关 Logo。
风格错误：不要模板网站风、廉价广告感、过度 AI 滤镜。
内容错误：不要出现与主题无关的元素，不要错误颜色、错误奖杯形状、错误服装。
画质错误：不要低清、噪点过重、过度锐化、过度磨皮。
```

## 常用高价值表达

- "请严格保留……"用于图像编辑和人物一致性。
- "不要通过……来制造变化"用于防止模型偷懒。
- "整体不是普通拼贴，而是……"用于提升海报和合成质量。
- "所有元素必须强绑定主题"用于防止无关装饰。
- "看起来像真实可生产的实体商品"用于产品和包装。
- "不要商业模板感 / 不要 App 组件风 / 不要 AI 味"用于避免廉价生成感。
- "前景 / 中景 / 背景分别包含……"用于稳定构图。
- "数量核对、尺寸检查、颜色一致性、结构稳定性"用于复杂产品图验收。
