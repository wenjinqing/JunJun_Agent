# GPT Image 2 提示词示例

## 示例 1：通用母版 - 双人冬景

**输入：** 两个少女坐在冬日奶茶店里喝奶茶，窗外下雪

**输出：**
请生成一张日系清新动漫插画，主题是「双人冬日奶茶店」，画面比例为3:4竖版，用于插画展示。

画面核心：
主体是两名少女，并排坐在奶茶店的木质吧台前。左侧少女金色短发蓝色眼睛，穿着黑色洛丽塔裙，双手捧着热芋泥奶茶，面带温柔微笑。右侧少女银色长发红色眼睛，穿着白色毛衣和编织围巾，端起抹茶拿铁。整体氛围温暖治愈。

视觉风格：
采用日系干净赛璐璐风格，柔和粉彩色调。光线从头顶暖灯洒下，与窗外冷蓝冬光形成冷暖对比。材质表现强调玻璃霜花纹理、奶茶杯的水汽凝结、毛衣的编织质感。

构图与镜头：
双人半身构图，浅景深。前景包含奶茶杯和散落的干花瓣，中景为两名少女，背景为大面积落地窗，窗外街道覆雪，暖黄路灯在暮色中亮起。

细节要求：
保留双人并排坐姿、奶茶杯、落地窗霜花、雪景街灯。强化玻璃霜花细节、杯具质感。

文字与版式：
画面中不需要出现文字。

避免：
不要文字，不要水印，不要肢体变形，不要元素堆砌。

## 示例 2：人像编辑 - 保留身份升级

**输入：** 一张女孩的正面自拍照，帮她提升质感，但不能变成另一个人

**输出：**
请基于用户上传的正面形象照片，生成一张高完成度的人像美学升级图。

必须严格保留：
本人身份特征、脸部辨识度、五官核心轮廓、年龄感、皮肤真实纹理、原本气质。

允许优化：
面部精神状态、皮肤质感、光线、轮廓清晰度、五官协调度、照片完成度。

禁止：
不要换头，不要变成模板网红脸，不要改变年龄，不要改变种族特征，不要过度磨皮，不要改变服装来制造变化，不要让人认不出原本人。

## 示例 3：动漫角色 - 剑士立绘

**输入：** 设计一个叫「青羽」的剑士角色，白发红瞳，穿着蓝色羽织

**输出：**
生成一张高完成度动漫角色设计图，角色为「青羽」。

角色设定：
年龄感为十七岁，气质冷峻孤傲，发色为银白渐变蓝，发型为高马尾长发放下，尾部有蓝色渐变，眼睛为赤红色，服装为蓝色羽织内搭白色和服，腰佩太刀，脚踩木屐。

设计要求：
画面包含正面主立绘、局部细节（刀镡纹样、羽织图案、发饰）、服装结构（羽织的层叠穿法、腰带系法）、配饰（银色耳坠、白色发带）、代表性道具（太刀、刀鞘）和主题色（蓝、白、红）。背景保持干净，辅助图形不能抢主体。

渲染要求：
线条精致，颜色统一，布料、金属刀镡、发丝等细节清晰，有高级游戏角色设定表质感。

避免：
不要低质量同人感，不要比例崩坏，不要手指错误，不要背景过花，不要配色混乱。

## 示例 5：摄影写真 - 胶片风街拍

**输入：** 一张女孩在傍晚街头的胶片感写真

**输出：**
生成一张胶片相机风格的人像摄影图，主体是穿着卡其色风衣的短发女孩，场景为傍晚城市街道。

相机参数：
设备类型为胶片相机（Contax T3），镜头为35mm焦段，构图为低角度半身，后期处理为暖调胶片风格。

主体描述：
人物具有自然微卷的短发、清透妆容、卡其色风衣内搭白色衬衫、深蓝牛仔裤，一手插兜一手拿着咖啡杯，表情自然随意，需要呈现慵懒随性的气质。

环境与灯光：
场景为傍晚的老城区街道，光线为5500K黄昏柔光，从侧后方逆光照射，发丝有金色边缘光。材质和皮肤质感为真实皮肤纹理，微颗粒感。

避免：
不要过度磨皮，不要假棚拍感，不要错误服装，不要不自然姿势，不要过度胶片颗粒。

## 示例 7：游戏资产 - 卡牌主视觉

**输入：** 生成一张「霜月剑姬」的 SSR 卡牌主视觉

**输出：**
生成一张二次元风格的角色主视觉，角色为「霜月剑姬」，核心技能效果为「冰霜月轮斩」。

角色：
角色拥有银白色长发、冰蓝色眼瞳、穿着白蓝渐变的战甲裙，动作是跃起挥剑下劈。

技能特效：
技能表现为冰蓝色月牙形剑气轨迹、碎裂的冰晶粒子、寒霜雾气环绕，围绕剑锋有银色光点，需要与角色主题强绑定。

画面：
采用低角度仰视、动态构图，主体清晰占据画面中央偏上，背景为碎裂的冰面与满月。整体有高级抽卡游戏主视觉质感。

避免：
不要技能效果与角色无关，不要武器形状错误，不要特效遮挡主体，不要低质量手游广告感。
