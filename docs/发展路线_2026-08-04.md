## 第 0 阶段：上线验证周（本周，0 新代码）

> 目标：重启全量上线 → 逐项验证 → 观察 ≥5 天 → 问题清零或降级。

### 0-1 上线（0.5 天）
1. 重启 bot + adapter（两侧都有改动）
2. 跑《生产验证清单_2026-08-03》欠账（感知补发、video_watch、订阅 R18 打码、TTS 情绪试听）
3. 本批新增验证项（补进清单）：
   - 学姐人设：群里自然聊 1 小时——撩的分寸、安慰响应、语气词全禁下暖度
   - 复读治理：观察日志 `复读自检命中` / `口头禅` 出现频率；**误伤信号** =
     该回的时候沉默变多（对比前后回复率）
   - 情绪系统：观察 `情绪变化` 日志——应随对话流动，不再卡死单一情绪
   - 发送重试：adapter 日志 `历史确认免重发`（EventChecker 误报被正确识别）
     与 `补发一次`；**盯双发**——同一条消息出现两遍说明误报判断失效
   - 声口统一：触发一次提醒/观后感/任务汇报，听是不是她的声口

### 0-2 观察期（5 天，每天 10 分钟看板）
- Langfuse：幻觉复发（搜「发了/唱了/画了」类无工具轮）、意图补救轮频率、
  echo 追问轮频率（`echo-retry` tag）
- DB：`selfmood` 表——情绪应每天变化；`llm_usage`——token 成本无异常膨胀
- 日志：发送重试触发次数与成功率
- **降级开关备忘**（出问题秒回滚）：
  - echo guard 误伤 → `[agent] echo_guard = false`
  - 口头禅太敏感 → `echo_catchphrase_count` 调大
  - 人设串味 → 恢复 `bot_config.toml.bak_2026-08-04`
  - 发送重试双发 → adapter 回滚到 c43435c 之前

### 0-3 串味处置（按需）
旧日记/身份认知是傲娇时期沉淀的，新人设前期可能「串味」。
观察 3 天仍明显 → 做 `/重置自我`（清空 identity 条目+近期日记权重归零，
保留长期事实记忆）——这个功能本身就值得顺手补，roadmap P6-3 提过兜底但没做。

**验收**：5 天观察无 P0 问题；验证清单全勾；降级开关零使用或已收敛。

## 第 1 阶段：意向系统灰度（下周起，1~2 周）

> 前提：第 0 阶段通过。意向是「像真人」最大一跃，也是扰民/风控最大来源——
> 原计划「护栏先行、灰度放量」不变。

### 1-1 私聊单点灰度（3 天）
- `intention.enable = true` + 目标限定**管理员私聊**（最小爆炸半径）
- 全局限流 5 条/天、免打扰 23:00-9:00、每日检查拦截日志
- 观察：意向生成质量（动机是否合理）、评估门误杀率、消息尬不尬

### 1-2 单群灰度（4 天）
- 扩大到 1 个活跃群，上限 3 条/天/群
- 重点观察：群友反应（被关心是惊喜还是被打扰）、话题去重（不炒冷饭）

### 1-3 全量 + evolution 灰度（并行）
- 意向全量，限流梯度放松；`evolution.enable = true` 技能补丁复盘开跑
  （有 `/补丁` 人工门控，风险低）
- **验收**：连续 7 天零投诉零风控；主动消息正反馈（被接话率）> 50%

## 第 3 阶段：新战场候选（P7 稳定后，按价值排序）

> 2026-08-04 实战中长出来的新需求，按「像真人」增益排序：

### 候选 A：语气词实验（0.5 天，建议最先做）
学姐人设的暖很大程度靠软粒子传递，当前「不用语气词」全禁偏冷。
A/B 思路：放宽为「语气词少用，别每句都带」观察 3 天，暖度 vs AI 味权衡。
**成本极低，体感收益可能极大。**

### 候选 B：/重置自我（1 天，0-3 的正式版）
管理员命令：清 identity 条目 + 日记权重重置，人设切换/长歪时的一键复位。
P6-3 兜底承诺，迟早要做。

### 候选 C：WS outbox 队列（2 天，按需触发）
网关→adapter 断连期消息目前记日志丢弃。若第 0 阶段观察到实际断连丢消息
≥1 次/周 → 做持久化 outbox（SQLite 表 + adapter 重连后回放）。
没观察到就不做（YAGNI）。

### 候选 D：多模态记忆图片化（2~3 天，长线）
「你上周发的那张图」目前只有文字描述。图片感知描述进 embedding 索引，
语义召回能想起图。P6-1 的自然延伸，但优先级低于 A/B。

### 候选 E：群氛围感知（3 天，调研阶段）
她现在只知道「自己被怎么对待」，不知道「群里今天在过年还是在出殡」。
群级情绪/活跃度摘要进上下文——安慰/捧场的时机感会更像人。
需要先做调研设计，不急着动工。
