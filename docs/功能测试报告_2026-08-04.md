## 五、pytest 发现的真问题（已修复）

**测试自污染（2 个失败，同一根因）**：
- `test_perception_followup::test_pending_hint_injected` 的 stub 图片 `b"img"`
  的 VLM 描述被写入**生产** Images 缓存表；下一轮运行缓存命中返回
  「一只橘猫」，测试期望的「还在看」提示不再出现——测试毒死了自己
- `test_w1w2_final` 每次运行向生产 Images 表写入 uuid 随机 hash 垃圾行
- 修复：两个测试改内存库 bind_ctx；生产表污染行已删除（b798abe6 一行）
- **教训沉淀**：凡触达 `junjun_core.database` 模型的测试必须内存库 bind_ctx，
  这与 8-04 早些时候的 selfmood 误写事件同类——已在两处测试中加注释告警

## 六、结论

1. **全部 55 个 LLM 工具可用**，无功能性损坏；主动决策工具链（搜索/记忆/
   P站/B站/天气）实调全部通畅
2. 需修复（代码级）：list_reminders docstring 过短、遗留插件空壳清理
3. 需关注（非 bug）：两个「历史上的今天」功能重叠（fun_texts.today_in_history
   与 news.get_today_in_history 同名不同源），建议保留现状（各有命令入口），
   或后续合并
4. 配置建议：补谷歌搜索 key 防 web_search 单点
